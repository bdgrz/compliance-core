## Wiring and next capabilities

Root DI currently wires request record/revise/assign/resolve/reopen, response create/revise/submit/review/deliver/disposition, admitted comment/sample materialization, population define/generate/classify/reconcile/freeze/amend/export, and package create/amend/build/validate/override/disclosure approval/delivery. Canonical withdrawal/discard/comment-correction workflows and automatic disclosure consumer are missing.

Small dependency-ready candidates to qualify: (1) manifest.json inside existing deterministic package zip; (2) delivery-time exact artifact shareability guard over existing selected content, without changing accepted historical delivery receipts. Canonical requester-side workflows depend on Examination EX-13/assigned-attest authority; new population/package identities require coordinated sample/signing consumers. This handoff is not execution proof or context completion.
