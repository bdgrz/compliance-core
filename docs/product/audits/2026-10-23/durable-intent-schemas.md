# Durable intent and result schemas

Concrete server-created records for selected target protocols; implementation is pending. Native facts reference verified complete immutable content, not raw request snapshots. Nullable fields are explicitly present. [Closed enums/unions](target-contract-types.json), [canonical input](canonical-intent-contracts.json), [revision/result semantics](revision-and-response-contracts.md) and [native acceptance](native-acceptance-contract.md) are normative.
