# Selected aggregate split boundaries

This is the selected target design; implementation is pending. Exact source command names replace earlier speculative aliases. [Target commands](target-command-contracts.md) define route/fields/handler; [owner protocols](owner-protocols.md) define invariants and races; [target events](target-event-contracts.md) define payload replacements. `commandMigrationMap` accounts for every current command, including proof-only dependencies, technical requests and the obsolete migration command. For native operation uniqueness, [#1042](https://github.com/bdgrz/compliance-core/issues/1042) is an explicit prerequisite.
