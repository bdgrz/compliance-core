# Target domain event contracts

Selected target schemas; backend implementation is pending. The JSON companion includes concrete fields, named immutable schemas, reducer rules and source pointers. Disposable histories permit direct replacement; every producer/consumer changes with its owner slice. Current-source schemas remain a migration reference.

Every native fact carries OperationProvenance plus nullable FirstResponse/OperationResult refs. Only the first native accepting fact stores that logical command FirstResponse; declared terminal facts store exact original typed results. See [native acceptance](native-acceptance-contract.md), [durable schemas](durable-intent-schemas.md), and [result contracts](operation-outcome-contracts.json). Technical stages, parent snapshot arrays and bearer data stay out of events.
