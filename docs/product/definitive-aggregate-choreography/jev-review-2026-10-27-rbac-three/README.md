# Role, Team and TeamMember aggregate review

- **Role:** one tenant/role identity owns definition, current name and terminal deletion; built-in roles cannot be deleted. A built-in role may still be initialized through the established rename migration. A custom role cannot be created by renaming an undefined role. Normal definition uses the role identity.
- **Team:** one tenant/team identity owns definition and terminal deletion; built-in teams cannot be deleted. Definition uses the team identity.
- **TeamMember:** one tenant/team/member relationship owns its current assignment and exact membership episode. Removing the relationship and assignment for a later episode remain independent transitions. Membership eligibility and cleanup are decided by their existing owners.

The new aggregate checks reject mismatched role/team ownership, invalid creation identity and terminal or built-in lifecycle violations during replay. TeamMember rejects an assignment with no membership episode. Invalid stored facts that previously replayed will now fail hydration; existing persisted history has not been audited for such facts. No event contracts or framework infrastructure were changed.
