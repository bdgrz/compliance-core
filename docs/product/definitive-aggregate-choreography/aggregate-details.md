# Selected canonical business and authority owners

**131 business/authority owners are selected.** The 2026-10-29 polish added `ApplicationNameClaim` (Jev 0.83) and moved `WorkDigestPreference` to the technical state owners (Jev 1.00), keeping the count at 131. Identities state the creation-key rule; invariants carry the concrete product rules they enforce; `productRules` in `aggregates.json` and [product rule traceability](product-rule-traceability.md) map every governed decision-record rule to its owner or disposition.

This defines the intended architecture. It does not authorize implementation, mark current code complete, or convert stored bytes. Planned facts and the planned owner have no declared source type yet.
